# 🤖 Basic Chatbot

## 📌 Description

A simple Python-based chatbot that interacts with users by responding to basic questions and commands. It demonstrates basic conversation logic using user input and conditional statements.

## ✨ Features

* 💬 Responds to basic user questions
* 👋 Handles greetings
* 🔄 Provides interactive conversations
* ❌ Handles unknown inputs
* 🚪 Allows the user to exit the chatbot

## 🛠️ Technologies Used

* Python 3
* Jupyter Notebook / Google Colab

## 🧠 Concepts Used

* Variables
* User input
* Strings
* `if-elif-else` statements
* Loops
* Basic conversation logic

## ▶️ How to Run

1. Open the Python file or Jupyter Notebook.
2. Run the program.
3. Enter a message when prompted.
4. The chatbot will respond based on the input.
5. Type the exit command to end the conversation.

## 🎯 Objective

The objective of this project is to create a simple interactive chatbot while learning fundamental Python programming and conversational logic.
